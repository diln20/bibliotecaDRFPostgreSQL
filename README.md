# DRF + PostgreSQL Academy

Biblioteca educativa en HTML inspirada en la estructura progresiva de `bibliotecaDjango`.

Incluye:

- Fundamentos de HTTP, REST y JSON.
- Conceptos básicos de bases de datos relacionales.
- PK, FK, relaciones 1:1 / 1:N / N:M, normalización y restricciones.
- SQL básico, filtros, CRUD, JOIN y GROUP BY.
- Instalación y uso básico de PostgreSQL.
- Django 6.1 + Django REST Framework 3.18.x.
- Conexión con PostgreSQL mediante psycopg 3.
- Models, migraciones, ORM, serializers, ViewSets y Routers.
- Validación, paginación, filtros, autenticación y permisos.
- Pruebas y proyecto final listo para comparar.

Abre `index.html` en el navegador.
